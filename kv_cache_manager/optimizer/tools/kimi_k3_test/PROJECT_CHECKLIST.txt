📞 问题排查
═══════════════════════════════════════════════════════════════════════════════

问题 1: 脚本执行失败
解决:
  1. 检查环境变量: echo $K3_REPO $K3_PY
  2. 检查文件存在: ls -lh $K3_TRACE $K3_MODEL
  3. 查看错误信息（脚本会显示详细错误）

问题 2: bench 阶段耗时太长
解决:
  1. 减少容量点: CAPACITIES="0,250,infinite"
  2. 减少请求数: REQUESTS_PER_SESSION=12
  3. 检查 trace 大小

问题 3: 验证失败 (validation.json passed=false)
解决:
  1. 查看 validation.json 中的错误信息
  2. 检查 metrics.json 中的指标
  3. 查看详细日志: $K3_RUN/stage2/*/logs/

问题 4: 图表未生成
解决:
  1. 检查 stage1 和 stage2 是否成功
  2. 单独运行 plot: --steps plot
  3. 检查 Python 依赖（matplotlib 等）
