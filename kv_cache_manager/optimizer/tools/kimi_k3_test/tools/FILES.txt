核心文件（必需）
================================================================================

1. compute_capacity_data.py (7.7K)
   - 功能: 计算容量曲线数据
   - 来源: run_workflow.py scan() 函数（第 330-407 行）
   - 输入: trace.jsonl, layout.json, litehit_config.json
   - 输出: capacity_data.json, capacity_curve.csv
   - 依赖: lite_hit_main, lite_hit_facts_query_main

2. plot_capacity_curve_axes0.py (5.4K)
   - 功能: 绘制 axes[0] 容量曲线图
   - 来源: analyze_results.py plot_and_report() 函数（第 380-395 行）
   - 输入: capacity_data.json, trace_manifest.json, layout.json
   - 输出: capacity_curve_axes0.{png,svg,pdf}
   - 依赖: matplotlib, numpy

3. run_example.sh (3.3K)
   - 功能: 一键运行示例脚本
   - 智能检测: 自动识别 stage1 数据或 litehit_config
   - 使用: ./run_example.sh <input_dir> [output_dir]
   - 权限: 可执行 (chmod +x)

================================================================================
使用流程
================================================================================

方式 1: 使用现有基线数据（推荐，秒级完成）
──────────────────────────────────────────
./run_example.sh \
    /workspace/dynosim_aic_sweep/reports/kimi_k3_litehit_hisim_20260909/agentx_sample \
    ./test_output

方式 2: 完整计算（需要 2-5 分钟）
──────────────────────────────────────────
# 步骤 1: 计算数据
python compute_capacity_data.py \
  --trace prepared/trace.jsonl \
  --layout prepared/layout.json \
  --litehit-config prepared/litehit_config.json \
  --output-dir output

# 步骤 2: 绘制图表
python plot_capacity_curve_axes0.py \
  --capacity-data output/capacity_data.json \
  --trace-manifest prepared/trace_manifest.json \
  --layout prepared/layout.json \
  --output-dir output
