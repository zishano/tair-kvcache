5. 功能特性
════════════════════════════════════════════════════════════════════════════

5.1 核心功能
────────────────────────────────────────────────────────────────────────────
✓ 容量数据计算
  • 运行 LiteHit 工具生成 Facts（容量无关的访问记录）
  • 查询 43 个容量点：0, 25, 50, 75, ..., 1000, 1024, ∞
  • 独立 LRU 缓存验证（7000+ 次检查）
  • 计算关键指标：elbow（几何拐点）、95% 点
  • 输出 JSON 和 CSV 格式

✓ axes[0] 图表绘制
  • 绘制容量 vs 命中率曲线（蓝色实线，带点标记）
  • 绘制无限容量基准线（紫色虚线）
  • 标注 Elbow 点（橙色）- 几何拐点，收益/成本最优平衡点
  • 标注 95% 点（青色）- 达到无限容量 95% 的最小容量
  • 标注 Plateau 点（绿色）- 曲线平台点（如果存在）
  • 输出 PNG、SVG、PDF 三种格式

✓ 智能运行脚本
  • 自动检测输入类型（stage1 数据或 litehit_config）
  • 智能选择执行路径（直接绘图或完整计算）
  • 一键运行完整流程

5.2 关键算法
────────────────────────────────────────────────────────────────────────────
Elbow 计算（几何拐点）:
  knee = max(finite, key=λ(c,h): 
      (h - h_min) / (h_max - h_min) - c / c_max
  )[0]
  
  含义: 在归一化坐标系中，收益曲线与对角线距离最大的点，
        表示容量投入的边际收益开始显著下降的拐点。

95% 点计算:
  cap95 = first(c where h >= 0.95 × h_infinite)
  
  含义: 第一个达到无限容量命中率 95% 的容量点，
        表示接近最优性能所需的最小容量。

独立验证:
  使用 OrderedDict 实现独立的 LRU 缓存模拟
  对每个容量点重放所有请求（7000+ 次检查）
  确保 LiteHit Facts 查询结果的准确性

6. 使用方法
════════════════════════════════════════════════════════════════════════════

6.1 方式 1: 使用现有基线数据（推荐，秒级完成）
────────────────────────────────────────────────────────────────────────────
cd /mnt/nvme1n1/data/lmk/Github/tair-kvcache/kv_cache_manager/optimizer/tools/kimi_k3_test

./run_example.sh \
    /workspace/dynosim_aic_sweep/reports/kimi_k3_litehit_hisim_20260909/agentx_sample \
    ./test_output

# 查看结果
ls -lh ./test_output/capacity_curve_axes0.*

6.2 方式 2: 完整计算（需要 2-5 分钟）
────────────────────────────────────────────────────────────────────────────
K3_PY=/workspace/tair-kvcache/.venv/bin/python
K3_TEST=/mnt/nvme1n1/data/lmk/Github/tair-kvcache/kv_cache_manager/optimizer/tools/kimi_k3_test

# 步骤 1: 计算容量数据
"$K3_PY" "$K3_TEST/compute_capacity_data.py" \
  --trace prepared/trace.jsonl \
  --layout prepared/layout.json \
  --litehit-config prepared/litehit_config.json \
  --output-dir output

# 步骤 2: 绘制图表
"$K3_PY" "$K3_TEST/plot_capacity_curve_axes0.py" \
  --capacity-data output/capacity_data.json \
  --trace-manifest prepared/trace_manifest.json \
  --layout prepared/layout.json \
  --output-dir output

6.3 方式 3: 只绘图（使用现有数据）
────────────────────────────────────────────────────────────────────────────
"$K3_PY" "$K3_TEST/plot_capacity_curve_axes0.py" \
  --capacity-data baseline/stage1/summary.json \
  --trace-manifest baseline/trace_manifest.json \
  --layout baseline/layout.json \
  --output-dir output
